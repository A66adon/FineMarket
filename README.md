# DeckCart

Private Chrome/Brave extension that turns an open Moxfield deck into a cheaper
Cardmarket cart, optimising cards, postage, order count and delivery time.

> Unofficial tool. Not affiliated with Cardmarket or Moxfield. Personal use only.

## Status

Early build. See `PRODUCT.md` for the locked product scope and `research/` for
the site, shipping and testing findings that drive the implementation.

## Scope

- Chrome and Brave on desktop (Manifest V3)
- MTG only
- Moxfield link or open deck tab; no CSV
- English cards only, EX or better
- Cheapest playable by default; exact deck as a secondary mode
- Board and basic-land toggles
- Reviews plans before touching the real cart; never checks out or pays
