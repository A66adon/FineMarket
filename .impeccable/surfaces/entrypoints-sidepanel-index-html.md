# DeckCart side panel

Mode: Operate. Chrome/Brave side panel, 380–480px; full-tab fallback at 1200px.

## Direction contract

THESIS: A vendor's card-sorting tray turned into a live order desk: the deck is sorted into seller stacks, and the cost of every extra order is visible before it is made. Refuses the generic dark dashboard with one accent and a card grid.

OWN-WORLD: Warm putty ground `#E8E1D4`, ink shell `#1E2420`, safety-orange primary `#E4572E`, ultramarine links/data `#1F4E79`, green savings `#2F6B4F`. System grotesque, tabular numerals, hairline rules, dense vertical stacking. Signature: the order rail, a charcoal strip of seller stops whose line state (solid, dashed, doubled) encodes order status and cost.

STORY: The visitor sees the deck as a set of seller stacks, understands landed total versus order count and slowest ETA, and chooses a plan before touching the cart.

FIRST VIEWPORT: Dark top bar with DeckCart and deck receipt. Below, a narrow control tray: board chips, basics toggle, Cheapest playable / Deck as listed switch. Then three plan lanes (Cheapest, Fewer orders, Fastest) with total, orders, ETA. Seller stacks fill the middle. The order rail is pinned above the apply footer.

FORM: Grounded candidate 6 of 7: the sorting tray. Seed: 95e63ae58b8c40d1. Code-led Operate surface.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
